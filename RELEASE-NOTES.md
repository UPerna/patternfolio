# Florilegium common platform release candidate

This candidate brings 22 generation profiles under the same Lua contracts and PDF/SVG renderer. It retains the historical floral workflows and adds shared recipes, validated-instance replay, document planning, both TeX adapters and the local browser studio.

The profiles include botanical layouts, periodic and finite substitution tiles, Celtic strands, classical and freeform Islamic ornament, Penrose P3, Spectre, Ammann–Beenker and Hat patches, bounded square completion, Gothic tracery, Escherization witnesses, mosaics, field and example strokes, guided mazes, micrography, exemplar brush synthesis, collection ornaments and projected Gothic curve networks. The [coverage ledger](docs/research/COVERAGE.csv) states each required capability and its evidence. Six optional research extensions remain separate.

The generated Pattern Atlas contains original canonical examples and separately named presentation variants, with recipes and complete replay bundles. Compass Garden supplies a book collection, a facing-page aperiodic view and hybrid ornament. The [quickstart](docs/QUICKSTART.md) covers command line, LuaLaTeX, XeLaTeX and the browser.

Candidate components contain canonical source, a runnable browser folder, the atlas, notices and checksum manifests. The dependency record pins the tested CI actions and native image. The verification receipts identify the exact revision, native builds, source-only reconstruction and comparison policy.

Fixed-source component archives have deterministic bytes and stored file modes. Same-runtime instance replay checks exact vectors. Named cross-runtime numerical comparisons retain independent geometry and semantic checks; their tolerance does not establish general mathematical correctness. Finite examples do not imply unbounded coverage or optimizer convergence.

See [compatibility and license notes](docs/COMPATIBILITY.md) for tested environments and boundaries. Native Windows TeX, other browsers/devices, Office imports and production printing are untested. The Windows Lupa functional test host needs an ASCII source path. No production site, upstream merge or public release tag is part of this candidate.

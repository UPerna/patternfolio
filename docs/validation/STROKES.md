# Stroke fields and example textures

The `stroke/fields-and-examples@1` provider exposes three named modes. The reusable `pattern_stroke_field` module defines centimeter direction and density queries, segment clearance in a rectangle with circular exclusion holes, and bounded midpoint integration. Each hatch traces both directions from its seed. It records boundary, hole, singularity, clearance or step-budget termination. Density-controlled stippling samples a normalized linear density ramp, with finite attempts and explicit domain and spacing rejections.

The example mode uses original vector inputs with editable group labels. It fits principal-axis boxes, greedily merges nearby or collinear continuing elements in drawing order, and refits the resulting elements. The causal profile follows Barla et al. (R10a) in expanding outward and comparing relative-offset neighborhoods through mutual nearest matches. Its bounded score combines angular, length, thickness, shape, offset, group and color differences. Low-quality matches use the seeded independent choice. Ranking uses fixed 10⁻⁹ bins with declaration-order ties, so last-bit rounding cannot choose a different equal-ranked candidate. This profile uses a jittered finite site grid and a bounded weighted score in place of the original full distribution-matching and perceptual threshold schedule.

The group profile follows R10b in recording nearest-neighbor proximity and the acute angle, bisector-relative overlap and separation of line pairs. Point pairs use proximity. It runs a bounded sampled Lloyd adjustment toward the reference spacing variation, then corrects position and orientation against the nearest previously accepted neighbor. Sampling draws bounded Gaussian attributes, copying chooses each attribute independently, and cloning retains the selected element's properties. The bounded profile synthesizes in 2D and uses the user-selected physical grid spacing and scale. It records the observed spacing variation and the applied match or correction decisions.

Example analysis and synthesis are separate from the hatch and stipple generators. All modes generate real stroke and dot paths. The independent checker tests segment and ink containment, intergroup clearance, analytic tangent error, tone distributions, example clustering and pair statistics. The declared modes use finite geometric guards. Source works and their illustrations remain private.

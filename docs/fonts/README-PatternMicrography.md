# Pattern Micrography font resource

Pattern Micrography is a renamed and subsetted derivative of Latin Modern Math 1.959 by B. Jackowski, P. Strzelczyk and P. Pianowski on behalf of TeX users groups. Original 2012–2014 copyright records remain in the embedded font. The font and exported outlines use the GUST Font License, an instance of LPPL 1.3c or later. The license texts accompany this file in GUST-FONT-LICENSE.md and LPPL-1.3c.md. Original authors do not provide support for the derived work.

The subset retains a bounded Latin and Greek repertoire, the source accented glyphs and the true fi and fl outlines. Preparation renamed the font, removed unrelated glyphs, hints, math and shaping tables, and fixed timestamps. The preparation tool verifies every retained outline, bound and advance against the original. Runtime shaping uses the declared repertoire and maps the two-character fi/fl ligatures and supported decomposed Latin acute clusters to the corresponding retained glyphs while keeping the original Unicode sequence.

The original work is available from [CTAN Latin Modern Math](https://mirrors.ctan.org/fonts/lm-math.zip). The exact source bytes match the [pinned distribution copy](https://github.com/valxyz/fonts-lm-math/blob/a0bb94c14db8e1f950d344e1eb1d5947c0182665/fonts/latinmodern-math.otf) and SHA-256 6075562b771f8b82f0c179e363389684f2dd09de30038269e2628e504bd7be0f. The derived embedded OTF SHA-256 is 9b9f100958cca036fcc3102719c91ba3804a362ebc215d5ecc16d6f38d9add69. Reproduce with tools/preparemicrofont.py, fontTools 4.60.1, the pinned source and an explicit output path.
